# 🔍 Prompt Checker

An interactive web application designed to evaluate, analyze, and optimize your AI prompts. Whether you are prompting ChatGPT, Claude, or midjourney, this tool helps you refine your prompt quality to get the best possible responses from AI models.

## ✨ Features
- 📊 **Prompt Scoring:** Instant quality rating for your prompts based on clarity, context, and structure.
- 💡 **Smart Suggestions:** Recommendations on how to improve weak prompts into high-converting outputs.
- ⚡ **Fast & Responsive:** Clean, lightweight user interface built for seamless user experience.

## 🛠️ Built With
- **Frontend:** HTML5, CSS3, JavaScript
- **Logic & Backend:** Python
- **Core Concept:** AI Prompt Engineering & Analysis
